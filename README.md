# Cars Dealership Capstone Project

Welcome to the Cars Dealership Capstone Project. This is a full-stack web application for a national car retailer, consisting of a Django/React application, a Node/Express/MongoDB microservice for dealer/review data, and a Flask microservice for sentiment analysis. It is designed to be deployed via Docker/Kubernetes to IBM Cloud Code Engine with a CI/CD pipeline using GitHub Actions.

## Microservices
- Django backend
- React frontend
- Express/Node microservice
- Flask sentiment analysis microservice
